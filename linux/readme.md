# NSIEP Keyboard Layout for Linux

This folder contains the necessary files to install and configure the NSIEP Norwegian keyboard layout for Linux, supporting both X11 and Wayland display servers.

## Quick Install

The easiest way to install is using the provided installation script that handles both X11 and Wayland configurations:

```bash
# Install system-wide (requires root/sudo)
sudo ./install.sh

# OR install for current user only (no root required)
./install.sh --user
```

After installation, log out and log back in for changes to take effect.

## Manual Installation

### For X11

1. Copy the keyboard layout file to the XKB symbols directory:
   ```bash
   sudo cp nsiep /usr/share/X11/xkb/symbols/
   ```

2. Add a layout entry to `/usr/share/X11/xkb/rules/evdev.xml`:
   ```xml
   <layout>
     <configItem>
       <n>nsiep</n>
       <shortDescription>ns</shortDescription>
       <description>NSIEP Norwegian</description>
       <languageList>
         <iso639Id>nob</iso639Id>
       </languageList>
     </configItem>
   </layout>
   ```

3. Add an entry to `/usr/share/X11/xkb/rules/evdev.lst`:
   ```
   nsiep           NSIEP Norwegian
   ```

4. Log out and log back in for changes to take effect.

### For Wayland

Wayland uses the same XKB files as X11 for keyboard layouts, so the basic installation steps are the same. However, configuration depends on your specific Wayland compositor:

#### GNOME (Wayland)

After installing the layout files:

1. Open Settings → Region & Language → Input Sources
2. Click the '+' button
3. Select "Other" and find "NSIEP Norwegian"
4. Click "Add"

Alternatively, you can use the command line:
```bash
# Add NSIEP layout to input sources
gsettings set org.gnome.desktop.input-sources sources "[$(gsettings get org.gnome.desktop.input-sources sources | sed "s/]$/, ['xkb', 'nsiep']]/" | sed "s/^@as //" | sed "s/\[\]/[['xkb', 'nsiep']]/" )]"
```

#### KDE Plasma (Wayland)

After installing the layout files:

1. Open System Settings → Input Devices → Keyboard → Layouts
2. Click "Add" and find "NSIEP Norwegian" under the Norwegian section
3. Click "Apply"

#### Sway/wlroots-based compositors

Add to your Sway config file (typically `~/.config/sway/config`):
```
input * {
    xkb_layout "us,nsiep"
    xkb_options "grp:alt_shift_toggle"  # Alt+Shift to switch layouts
}
```

Replace `us` with your default layout if different.

## User-Level Installation

If you don't have sudo access, you can install the layout for your user only:

1. Create the directory structure:
   ```bash
   mkdir -p ~/.config/xkb/symbols/
   ```

2. Copy the layout file:
   ```bash
   cp nsiep ~/.config/xkb/symbols/
   ```

3. For specific compositor configurations, see the user-level instructions generated by the install script.

## Troubleshooting

If the layout doesn't appear after installation:

1. Make sure you've logged out and logged back in
2. Check if the layout file was properly installed: `ls -la /usr/share/X11/xkb/symbols/nsiep`
3. For Wayland-specific issues:
   - GNOME: Run `gsettings get org.gnome.desktop.input-sources sources` to check if the layout is in the list
   - KDE: Check if the layout appears in System Settings
   - Sway: Restart sway after adding the configuration
